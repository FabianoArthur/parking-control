# Security Policy

## Supported versions

Only the latest commit on `main` receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's
[private vulnerability reporting](https://github.com/FabianoArthur/parking-control/security/advisories/new)
instead. You should get an answer within a few days. Once a fix is released, you will be
credited unless you prefer otherwise.
